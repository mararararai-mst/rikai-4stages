理解の構造を可視化する

「わかった」を分解する
理解の４段階

「わかった」は便利だが、曖昧でもある。
今、この生徒はどこに立っているのか——見取るための整理。

01　理解の４段階
1
事実的理解 「知っている」状態 点の知識
FACTUAL ▾

DESCRIPTION

用語や基本的な事実を知っている。問われれば正確に答えられる。知識はまだ点として存在している段階。学びの出発点として欠かせないが、点同士がどう関係するかはまだ見えていない。

EXAMPLE ／ 鎌倉幕府

・鎌倉幕府を開いたのは源頼朝
・将軍に仕えた武士を「御家人」という
・将軍と御家人の関係は「御恩と奉公」

「御家人とは？」と聞かれれば「将軍に仕えた武士」と答えられる。
2
関係的理解 「つながりが見え始める」状態 線の知識
RELATIONAL ▾

DESCRIPTION

「〜だから〜になる」「〜と比べて〜が違う」という言葉で説明できる。事実同士が理由や対比によって結びつき、知識が点から線へと変わっていく段階。

EXAMPLE ／ 鎌倉幕府

・将軍が土地を与えるから、御家人は命がけで戦う
・朝廷の政治と違って、武士が中心になって政治を行った

「御恩と奉公」が、将軍と御家人を結びつける関係として語られ始める。
3
構造的理解 「仕組みとして捉え直す」状態 面の知識
STRUCTURAL ▾

DESCRIPTION

図やモデルで表せる。説明の順序を自分で組み立てられる。自分の言葉に言い換えられる。全体としてどういう仕組みかを語れる状態。理解は点や線を超えて、面のように広がっていく。

EXAMPLE ／ 鎌倉幕府

将軍を中心に、御家人が土地を介して結びつき、軍事力によって政権が支えられている——全体像を図や文章で説明できる状態。

「御家人とは？」に対し、用語の説明でなく仕組みの中に位置づけて答えられる。
4
概念的理解 「具体を超えて考えられる」状態 抽象の知識
CONCEPTUAL ▾

DESCRIPTION

具体的な事例を越えて考えられる。原理や特徴として捉え直せる。別の場面にもつなげて説明できる。個別の内容を土台にしながら、より抽象的な視点に立つ理解。

EXAMPLE ／ 鎌倉幕府

「土地を媒介にした主従関係の政治」として捉え直せる。

・なぜ室町幕府でも似た関係が続いたのか
・なぜこの仕組みは次第に行き詰まったのか

鎌倉幕府を超えて「武士の政権とは何か」という概念に触れ始めている状態。

深い理解
02　構造的理解を生む活動の共通パターン
01

言語化させる

「なぜそうしたか」「どうなっているか」を説明させる。説明できるかどうかが③到達の最大の指標。

02

全体を俯瞰させる

部分ではなく作品・工程・献立の「全体」を見せる・考えさせる。構造は全体を見て初めて見えてくる。

03

評価・改善させる

「よかった」で終わらせず「なぜよかったか」「次どうするか」を問う。評価なき制作は①②で止まりやすい。

04

他者に伝えさせる

自分の意図・判断を他者に伝える活動が③を確認する機会になる。ペア共有・制作意図の記述など。

03　各教科の活動例
🎵 音楽
演奏が「できる」ことと「わかっている」ことは別。③には「なぜそう弾くか」を言語化させる活動が必要。
STAGE 01
事実的理解
音符・記号の名称を覚える楽譜を読む練習記号と意味を一致させる
STAGE 02
関係的理解
「この記号→こう演奏」を確認しながら弾く聴き比べて違いを言葉にする強弱と表現の関係を考える
STAGE 03
構造的理解
曲全体の構成を図に書く「なぜここでこの表現か」を説明する演奏解釈を他者に伝える
STAGE 04
概念的理解
別の曲で同じ構造を見つける作曲家の意図を時代背景と結びつける
🔧 技術
設計→制作→評価のサイクルが構造的理解を自然に生みやすい。4段階が最も当てはまりやすい教科。
STAGE 01
事実的理解
工具の名称・使い方を覚える材料の性質を知る手順書を読む
STAGE 02
関係的理解
「この工程だから次はこう」を話しながら作業する失敗の原因を考える
STAGE 03
構造的理解
設計図を自分で書く「なぜこの構造にしたか」を説明する改善点を提案する
STAGE 04
概念的理解
別の素材・目的で同じ原理を応用する「この技術は社会でどう使われているか」考える
🍳 家庭科
「おいしくできた」体験と「なぜおいしくできたか」の理解は別。③には評価と言語化の活動が必要。
STAGE 01
事実的理解
栄養素の名称を覚える調理用語を知るレシピ通りに作る
STAGE 02
関係的理解
「この食材→この栄養素→体にこう働く」を説明するレシピの意図を考える
STAGE 03
構造的理解
献立全体のバランスを自分で考えて説明する「なぜこの手順か」を原理から説明する作った料理を評価・改善する
STAGE 04
概念的理解
食文化・環境・経済と結びつけて考える「自分の食生活はどうあるべきか」を語る
🎨 美術
「感じる」と「わかる」が混同されやすい。③には「感じたことを根拠から説明する」活動が不可欠。
STAGE 01
事実的理解
色の三原色・遠近法の用語を知る見本を模写する
STAGE 02
関係的理解
「この色→こう見える」を言葉にする作品を比較して違いを説明する
STAGE 03
構造的理解
自分の制作意図を説明する（なぜこの色・構図か）鑑賞した作品の「仕組み」を図や言葉で整理する
STAGE 04
概念的理解
時代・文化・作者の意図を結びつけて読む「美術とは何か」を自分の言葉で語る
